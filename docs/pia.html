Tu PIA paso a paso: analiza datos de un API con Python

En este recurso vas a recorrer, etapa por etapa, un proyecto completo de ejemplo: "Personajes y mundos de Star Wars: análisis de datos con SWAPI". En cada etapa verás qué hizo el ejemplo y qué te toca hacer en tu propio PIA.

Inicio

Tu PIA paso a paso: analiza datos de un API con Python

Objetivo de aprendizaje. Al terminar, podrás aplicar las etapas de un proyecto de análisis de datos en Python (consultar un API, limpiar datos con expresiones regulares, elegir estructuras de datos, ordenar con un algoritmo recursivo y presentar resultados) usando como modelo el proyecto de SWAPI, para planear tu propio PIA.

El ejemplo que vas a seguir

Una aplicación en Python que descarga de SWAPI los 82 personajes y 60 planetas de Star Wars, los limpia con expresiones regulares, los analiza y descubre que la saga se cuenta desde planetas pequeños, no desde las grandes capitales.

Su pregunta fue: ¿de dónde vienen los personajes de Star Wars y qué tan parecidos son entre sí?

El programa se ejecuta de forma lineal: solo pide un dato al inicio y después realiza todo el proceso sin menús.

Tu ruta en este recurso

  1. Haz una pregunta y elige tu API (diapositiva 2)
  2. Descarga el JSON página por página (diapositiva 3)
  3. Limpia los datos con expresiones regulares (diapositiva 4)
  4. Elige tus estructuras de datos (diapositiva 5)
  5. Escribe el algoritmo en estilo Cairó y ordena con Merge Sort (diapositivas 6 y 7)

  7. Autoevaluación, resumen y lista de cotejo de tu documento (diapositivas 9 y 10)

Etapa 1

Haz una pregunta y elige tu API

Una saga con decenas de personajes y planetas parece imposible de resumir a simple vista. Por eso el proyecto empieza con una pregunta y un API público que regresa los datos en formato JSON.

El ejemplo eligió SWAPI, The Star Wars API (swapi.dev) porque cumple con todo lo que pide el proyecto:

CriterioCómo lo cumple SWAPI
Público y gratuitoNo requiere registro ni clave de acceso (API key).
Formato JSONCada respuesta es un objeto JSON con las llaves count, next, previous y results.
Datos que necesitan limpiezaLos números vienen como texto ("172"), con comas ("1,358") o como "unknown"; los años vienen como "19BBY".
Datos relacionadosCada personaje trae la URL de su planeta natal, lo que permite cruzar dos recursos.
Tamaño manejable82 personajes y 60 planetas, repartidos en páginas de 10 registros.

Usó dos recursos (endpoints): https://swapi.dev/api/people/ (personajes) y https://swapi.dev/api/planets/ (planetas).

Etapa 2

Descarga el JSON página por página

El API no entrega todo de una vez: lo reparte en páginas. El programa sigue el campo "next" hasta que vale None.

Un registro crudo, tal como llega

{
  "name": "Luke Skywalker",
  "height": "172",
  "mass": "77",
  "birth_year": "19BBY",
  "gender": "male",
  "homeworld": "https://swapi.dev/api/planets/1/",
  "url": "https://swapi.dev/api/people/1/"
}

Observa: la altura y la masa son texto, no números.

Recorrer todas las páginas

def obtener_recurso(recurso):
    registros = []
    url = URL_BASE + recurso + "/"
    while url is not None:
        respuesta = requests.get(url, timeout=TIEMPO_ESPERA)
        respuesta.raise_for_status()  # error si no es 200
        pagina = respuesta.json()     # texto JSON a diccionario
        registros.extend(pagina["results"])
        url = pagina["next"]          # None cuando ya no hay más
    return registros

Si no hay conexión, un bloque try/except atrapa el error (requests.exceptions.RequestException) y el programa continúa con la copia local datos/datos_crudos.json.

Etapa 3

Limpia los datos con expresiones regulares

Sin expresiones regulares, float("1,358") o float("unknown") detendrían el programa con un error. Las expresiones regulares validan el texto antes de convertirlo.
PatrónPara qué sirveEntrada → salida
, con re.subQuita las comas de miles antes de validar"1,358" → "1358"
^\d+(\.\d+)?$Valida que el texto sea un número entero o decimal completo"172" → 172.0 · "unknown" → None
^(\d+(?:\.\d+)?)(BBY|ABY)$Separa el número y la era del año de nacimiento con dos grupos"19BBY" → -19.0
/(\d+)/?$Extrae el id al final de una URL para enlazar personaje y planeta".../planets/8/" → 8
\s*,\s* con splitSepara una lista de climas escrita en un solo texto"temperate, arid" → {"temperate", "arid"}
\s+ con subReduce espacios repetidos en los nombres"Darth  Vader " → "Darth Vader"

Cómo leer los símbolos: ^ y $ marcan el inicio y el fin del texto, \d+ significa uno o más dígitos, ( ) forma un grupo que después se recupera con group(1), ? hace opcional lo anterior y | significa "o".

Probador: escribe un valor y mira qué regresa cada función

En la ejecución, la validación descartó como None: 1 altura desconocida (Arvel Crynyd), 23 masas y 39 años de nacimiento. La única masa con coma era la de Jabba Desilijic Tiure ("1,358"): gracias a re.sub entró al análisis en lugar de perderse.

Etapa 5

Escribe el algoritmo en estilo Cairó

Antes de programar, el algoritmo se escribe independiente del lenguaje: pasos numerados de forma continua, una operación por paso, asignaciones con ←, cierre de cada estructura con "Fin del paso N" y llamadas a procedimientos solo por su nombre. Las estructuras de datos se representan con arreglos y registros.

Explora: toca una línea del código o un paso del algoritmo

Python · limpiador_datos.py
Función A_NUMERO (estilo Cairó) y explicación

Descripción de variables. TEX: Variable de tipo cadena. Almacena el valor tal como llega del API, por ejemplo "1,358" o "unknown". VAL: Variable de tipo real. Almacena el número validado, o NULO si el texto no era un número.

El diagrama de flujo del algoritmo principal usa la notación ANSI: óvalo para inicio y fin, paralelogramo para entrada y salida, rectángulo para asignaciones, rombo para decisiones y rectángulo con doble línea lateral para procedimientos.

Etapa 5 (continuación)

Ordena con Merge Sort: divide y vencerás

ordenar_mezcla parte la lista a la mitad, ordena cada mitad llamándose a sí misma y une las dos mitades ya ordenadas con mezclar. El proyecto la usa dos veces: para ordenar alturas y para ordenar planetas por número de personajes.
def ordenar_mezcla(lista):
    if len(lista) <= 1:                      # caso base
        return lista
    mitad = len(lista) // 2
    izquierda = ordenar_mezcla(lista[:mitad])  # llamada recursiva
    derecha = ordenar_mezcla(lista[mitad:])    # llamada recursiva
    return mezclar(izquierda, derecha)

Ejecución paso a paso de mezclar

Entrada: izquierda = [(66, 'Yoda'), (172, 'Luke Skywalker')] y derecha = [(88, 'Wicket'), (264, 'Yarael Poof')], dos listas de tuplas (altura, nombre) ya ordenadas.

Etapas 6 y 7

Organiza tu programa en módulos y cuenta la historia de tus datos

El sistema es una tubería de cinco módulos coordinados por main.py: cada módulo recibe el resultado del anterior y entrega el suyo al siguiente. Ningún módulo llama a otro; solo main.py los conecta.

Lo que descubrieron los datos

82personajes de 49 planetas
21personajes vienen de Naboo (11) y Tatooine (10)
50personajes por millón de habitantes en Tatooine
3personajes de Coruscant, con un billón de habitantes

Un dato aislado ("Naboo tiene 11 personajes") no cuenta una historia hasta que se compara con otro (su población). En la gráfica de líneas de alturas ordenadas, la media (174.6 cm) cruza la curva cerca de la posición 30, no a la mitad (posición 41): los personajes bajos jalan la media hacia abajo y por eso la mediana (180 cm) describe mejor al personaje típico.
