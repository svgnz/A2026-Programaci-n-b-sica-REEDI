Idea clave 1

¿Qué es el módulo os?

Permite interactuar con el sistema operativo desde Python: consultar, crear, recorrer, renombrar y eliminar carpetas y archivos. Es parte de la biblioteca estándar: no se instala, pero sí se importa. Su submódulo os.path trabaja con rutas.

Conceptos previos

Carpeta
También llamada directorio: contenedor de archivos y otras carpetas.
Ruta relativa
A partir del directorio de trabajo actual: "Evidencias/Unidad2".
Ruta absoluta
Ubicación completa: "C:/Usuarios/Ana/Evidencias" o "/home/ana/Evidencias".
Directorio de trabajo
Carpeta desde la que Python resuelve las rutas relativas; normalmente, desde donde se ejecuta el programa.

Primer contacto

import os
print(os.getcwd())   # directorio de trabajo actual

Idea clave 4

  
Crear una carpeta y listar su contenido

  

    

      
Crear si no existe y listar

      
import os

carpeta = "Evidencias"

if not os.path.exists(carpeta):
    os.mkdir(carpeta)

contenido = os.listdir(carpeta)
print("Carpeta:", carpeta)
print("Contenido:", contenido)

      
Si se acaba de crear, muestra Contenido: []. Forma breve equivalente: os.makedirs(carpeta, exist_ok=True).

    

    

      
Distinguir archivos de carpetas

      
for nombre in os.listdir(carpeta):
    ruta = os.path.join(carpeta, nombre)
    if os.path.isdir(ruta):
        print("[Carpeta]", nombre)
    else:
        print("[Archivo]", nombre)

      
os.listdir() devuelve solo nombres del contenido inmediato, en un orden no garantizado. Por eso isdir() necesita la ruta completa que arma os.path.join().

Idea clave 7

  
Errores comunes y cómo prevenirlos

  

    
FileExistsErroros.mkdir() con una carpeta que ya existe.

    
FileNotFoundErroros.mkdir("A/B") si "A" no existe. Usa os.makedirs().

    
OSErroros.rmdir() con una carpeta que tiene contenido.

    
remove() con carpetaIsADirectoryError en Linux; PermissionError en Windows y macOS.

    
listdir() sin ruta válidaProduce FileNotFoundError.

    
walk() silenciosoCon la ruta mal escrita no hay error, pero tampoco resultados.

    
Solo el nombreopen(), isfile() o getsize() necesitan la ruta de os.path.join().

    
Windows sin r"C:\nueva" contiene un salto de línea. Usa r"C:\nueva" o "C:/nueva".

    
Otra carpetaLas rutas relativas se resuelven desde el directorio de trabajo, no desde el .py.

    
NameErrorOlvidar import os.

try:
    os.rmdir("Temporal")
except FileNotFoundError:

    print("La carpeta no está vacía.")

Resumen

  
Lo esencial del módulo os

  

    
Crear
os.mkdir() crea una carpeta; os.makedirs(ruta, exist_ok=True) crea las intermedias sin error.

    
Consultar
os.listdir() da el contenido inmediato; os.walk() recorre todos los niveles en un ciclo for.

    
Rutas
Ambas devuelven nombres: arma la ruta completa con os.path.join() y verifica con exists() o isdir().

    
Eliminar
os.rmdir() solo carpetas vacías; os.remove() solo archivos. Es permanente.

Para saber más: pathlib

    
Desde Python 3.4, el módulo pathlib trabaja las rutas como objetos y aparece en mucho código actual.

    
from pathlib import Path

carpeta = Path("Evidencias")
carpeta.mkdir(exist_ok=True)
for archivo in carpeta.rglob("*.py"):
    print(archivo)
