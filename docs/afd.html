Idea clave 1

¿Qué es un autómata finito determinista?

Un modelo matemático de cómputo que lee una cadena de símbolos, uno por uno, y decide si cumple una regla: la acepta o la rechaza. Es "finito" porque tiene un número limitado de estados y no tiene más memoria que el estado en el que se encuentra.

Definición formal: una 5-tupla

M = (Q, Σ, δ, q0, F)

Q
Conjunto finito de estados.
Σ
Alfabeto: conjunto finito de símbolos permitidos.
δ
Función de transición, δ: Q × Σ → Q. "Recibe un estado y un símbolo, y devuelve un estado". Ej.: δ(q0, 1) = q1.
q0
Estado inicial (q0 ∈ Q). Es único.
F
Estados finales o de aceptación (F ⊆ Q): uno, varios o ninguno.

¿Por qué determinista? Para cada estado y símbolo existe exactamente una transición: la tabla no tiene celdas vacías ni celdas con dos estados.

Conceptos relacionados

Símbolo
Elemento del alfabeto: 0, 1, a, b.
Cadena
Secuencia finita de símbolos: 1011.
Cadena vacía
Sin símbolos; se escribe ε o λ. Su longitud es 0.
Lenguaje
Conjunto de cadenas. L(M) es el conjunto de todas las cadenas que acepta M.

Se usa para

  • Reconocer patrones en texto: las expresiones regulares se implementan con autómatas.
  • Validar formatos: números, identificadores, matrículas, correos.
  • El analizador léxico de un compilador.
  • Modelar sistemas con estados: semáforos, máquinas expendedoras, elevadores, protocolos.

Idea clave 2

¿Cómo funciona? Simulador de AFD

Comienza en q0, lee la cadena de izquierda a derecha, cambia de estado con δ(estado actual, símbolo) y, solo al terminar de leer toda la cadena, acepta si el estado actual pertenece a F.

Convención: → marca el estado inicial y * los estados finales. En el diagrama, el estado final lleva doble círculo.

Idea clave 4

La 5-tupla en Python: tabla de transición con diccionario

Versión recomendada: representa directamente la 5-tupla. Para cambiar de autómata solo se modifican los datos, no el código.

# Definición del AFD: M = (Q, Σ, δ, q0, F)
Q = {"q0", "q1"}
SIGMA = {"0", "1"}
DELTA = {
    ("q0", "0"): "q0",
    ("q0", "1"): "q1",
    ("q1", "0"): "q0",
    ("q1", "1"): "q1",
}
INICIAL = "q0"
FINALES = {"q1"}

cadena = input("Ingresa una cadena binaria: ").strip()

estado = INICIAL
valida = True

for simbolo in cadena:
    if simbolo not in SIGMA:
        valida = False
        break
    estado = DELTA[(estado, simbolo)]

if not valida:
    print("Cadena inválida")
elif estado in FINALES:
    print("Cadena aceptada")
else:
    print("Cadena rechazada")

DELTA[(estado, simbolo)] es δ(estado, símbolo)

La clave del diccionario es la pareja (estado, símbolo) y el valor es el estado siguiente. Comparada con la versión con condiciones, aquí no hay un if por cada fila de la tabla.

Versión como función con traza

def simular_afd(cadena, delta, inicial, finales, sigma):
    estado = inicial
    print("Estado inicial:", estado)
    for simbolo in cadena:
        if simbolo not in sigma:
            return "inválida"
        nuevo = delta[(estado, simbolo)]
        print(f"δ({estado}, {simbolo}) = {nuevo}")
        estado = nuevo
    if estado in finales:
        return "aceptada"
    return "rechazada"

print(simular_afd("1011", DELTA, INICIAL, FINALES, SIGMA))
Estado inicial: q0 δ(q0, 1) = q1 δ(q1, 0) = q0 δ(q0, 1) = q1 δ(q1, 1) = q1 aceptada

Idea clave 6

Otros AFD: cuando el estado actual sí importa

Puedes probar los tres en el simulador de la diapositiva 3.

a) Número par de ceros

Q = {p, i} · Σ = {0, 1} · q0 = p · F = {p}

Estado01
→ * p (par)ip
i (impar)pi

Un 0 cambia de p a i o de i a p; un 1 no cambia el estado. Como el estado inicial también es final, ε se acepta (cero ceros es par).

DELTA = {("p", "0"): "i", ("p", "1"): "p",
         ("i", "0"): "p", ("i", "1"): "i"}
INICIAL = "p"
FINALES = {"p"}

b) Terminan en 01

Q = {A, B, C} · q0 = A · F = {C}. A: no hay avance; B: el último símbolo es 0; C: los dos últimos son 01.

Estado01
→ ABA
BBC
* CBA

c) Estado de error: inician con 1

Estado01
→ q0qeq1
* q1q1q1
qe (error)qeqe

Cuando la cadena ya no puede aceptarse, pasa a un estado del que no se sale. Así la tabla queda completa.

Idea clave 7

AFD y otros modelos; errores comunes

AFD
Una única transición por estado y símbolo. Fácil de simular.
AFN
No determinista: varias transiciones (o ninguna) para un mismo estado y símbolo, y transiciones ε. Todo AFN puede convertirse en un AFD equivalente.
Expresiones regulares
Describen los mismos lenguajes (lenguajes regulares). "Terminan en 1" corresponde a (0|1)*1.
import re
re.fullmatch(r"[01]*1", "1011")   # coincide: aceptada

Limitación: un AFD no tiene memoria adicional; no puede "contar sin límite", como en 0ⁿ1ⁿ (mismo número de ceros que de unos). Para ello se usan autómatas de pila.

Recomendaciones

  • Describe con palabras qué "recuerda" cada estado; si no puedes, sobra o falta uno.
  • Define la 5-tupla completa antes de programar.
  • Verifica que la tabla esté completa; si falta una transición, agrega un estado de error.
  • Con la cadena vacía, se acepta solo si q0 ∈ F.
  • Prueba aceptadas, rechazadas y casos límite: ε, un símbolo, cadenas largas y símbolos inválidos.
  • Haz la prueba de escritorio antes de ejecutar.

Actividad 4 · Revelar respuesta

Un estudiante programa el AFD "inician con 1", pero olvida el estado de error. ¿Qué ocurre con la cadena 01 y cómo se corrige?

DELTA = {("q0", "1"): "q1",
         ("q1", "0"): "q1", ("q1", "1"): "q1"}

Qué ocurre: al leer el primer símbolo se busca DELTA[("q0", "0")], que no existe: el programa se detiene con KeyError: ('q0', '0').

Corrección: completar la tabla con el estado de error qe, del que no se sale.

DELTA = {("q0", "0"): "qe", ("q0", "1"): "q1",
         ("q1", "0"): "q1", ("q1", "1"): "q1",
         ("qe", "0"): "qe", ("qe", "1"): "qe"}

Resumen

Lo esencial de los AFD

Definir

La 5-tupla M = (Q, Σ, δ, q0, F) y qué "recuerda" cada estado.

Determinismo

Exactamente una transición por estado y símbolo; un estado de error completa la tabla.

Decidir al final

Acepta solo si, tras leer toda la cadena, el estado actual pertenece a F.

Programar

DELTA[(estado, simbolo)] es δ(estado, símbolo); para otro AFD solo cambian los datos.
