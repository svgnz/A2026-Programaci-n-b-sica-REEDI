Idea clave 1

¿Qué es pandas?

Una biblioteca que organiza, consulta, analiza y modifica datos de manera sencilla, especialmente útil con tablas similares a las de Excel.

Se usa para

  • Leer y guardar datos en CSV y Excel.
  • Organizar información en filas y columnas.
  • Consultar, filtrar y ordenar registros.
  • Calcular promedios, sumas y otras estadísticas.
  • Identificar y tratar datos faltantes.
  • Agrupar por categorías (por ejemplo, promedio por grupo).
  • Preparar datos para graficar con matplotlib.

Idea clave 4

  
Filtrar filas con condiciones

  
La condición compara cada valor de la columna y produce una Series de True/False; df[…] devuelve solo las filas con True y conserva su índice original.

  

    

      df["Calificacion"]
      

      

      
    

  

  

    

      

      
1. La condición produce una Series de True/False

      

    

    

      
2. df[…] conserva solo las filas con True

      

      

      
Combina con & (y), | (o) y ~ (no), con cada condición entre paréntesis. Por texto: df[df["Estudiante"] == "Luis"]. El nombre de la variable debe decir lo que representa: >= 90 son destacados; aprobados serían >= 70.

    

  

  

    Actividad 3 · Revelar respuesta
    
Se quieren los estudiantes con calificación entre 85 (incluida) y 95 (excluida). ¿Qué ocurre con este código y cómo se corrige?

    
rango = df[df["Calificacion"] >= 85 and df["Calificacion"] < 95]

    

    

      
Qué ocurre: se produce ValueError: The truth value of a Series is ambiguous. and espera un solo True o False, y cada comparación produce una Series completa.

      
Corrección: usar & y encerrar cada condición entre paréntesis.

      
rango = df[(df["Calificacion"] >= 85) & (df["Calificacion"] < 95)]

Datos faltantes y errores comunes

  

    

      
Datos faltantes (NaN)

      
datos = {"Estudiante": ["Ana", "Luis", "Marta"],
         "Calificacion": [95, None, 90]}
df = pd.DataFrame(datos)

print(df.isna().sum())            # Calificacion: 1 faltante
print(df["Calificacion"].mean())  # 92.5 (ignora el faltante)

df_sin_vacios = df.dropna()       # elimina la fila de Luis
df_con_cero = df.fillna(0)        # Luis queda con 0

      
mean(), sum() y count() ignoran los faltantes: el promedio es 92.5 y no 61.67. Eliminar, rellenar o investigar cambia el resultado; revisa con df.isna().sum() antes de calcular.

destacados.to_csv("destacados.csv", index=False)
