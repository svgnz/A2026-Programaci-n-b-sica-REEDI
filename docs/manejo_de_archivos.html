Idea clave 1

¿Qué hace la función open()?

Abre un archivo para leer, escribir o agregar contenido, y devuelve un objeto archivo. Con ese objeto se trabaja mediante métodos como read(), write() y close().

Sintaxis básica

open("nombre_archivo.txt", "modo", encoding="utf-8")

Sus tres partes

"nombre_archivo.txt"
Nombre del archivo y, opcionalmente, su ruta.
"modo"
Operación que se realizará: leer, escribir, agregar o crear.
encoding="utf-8"
Codificación del texto. Especifícala siempre: la codificación por defecto depende del sistema operativo y puede dañar acentos y la "ñ".

Ejemplo

archivo = open("mensaje.txt", "w", encoding="utf-8")   # objeto archivo
archivo.write("Hola, Python")
archivo.close()

Idea clave 2

El modo define la operación

Elige un modo y la situación del archivo para ver qué hace Python. Si no indicas modo, se usa "r" (lectura en modo texto).


    

    
Modificadores: "t" texto (por defecto, "rt" = "r") · "b" binario para imágenes, audio o PDF ("rb") · "+" lectura y escritura a la vez ("r+": el archivo debe existir y no se borra).

Idea clave 3

  
¿Dónde busca Python el archivo?

  

    

      
Ruta relativa

      
Se busca a partir del directorio de trabajo actual.

      
open("datos/mensaje.txt", "r")

      
Para conocer ese directorio:

      
import os
print(os.getcwd())

    

    

      
Ruta absoluta

      
Indica la ubicación completa.

      
open("C:/Usuarios/Ana/mensaje.txt", "r")   # Windows
open("/home/ana/mensaje.txt", "r")         # Linux/macOS

      
En Windows, la diagonal invertida \ puede formar secuencias de escape como \n o \t. Usa diagonal normal o una cadena cruda con prefijo r.

    

  

  

    Actividad 2 · Revelar respuesta
    
Un estudiante ejecuta esta instrucción en Windows y el archivo no aparece donde esperaba. Analiza la cadena de la ruta: ¿qué problema tiene y cómo se corrige?

    
open("C:\Usuarios\nuevo.txt", "w", encoding="utf-8")

    

    

      
Problema: dentro de la cadena, \n de \nuevo.txt se interpreta como un salto de línea, no como la diagonal seguida de la letra n. La ruta resultante no es la que se escribió.

      
Corrección (cualquiera de las dos):

      
open("C:/Usuarios/nuevo.txt", "w", encoding="utf-8")
open(r"C:\Usuarios\nuevo.txt", "w", encoding="utf-8")

Idea clave 6

  
Leer y agregar contenido

  

    

      
Leer todo el archivo

      
with open("mensaje.txt", "r", encoding="utf-8") as archivo:
    contenido = archivo.read()
print(contenido)

      
Recorrer línea por línea

      
Recomendado para archivos grandes: no carga todo en memoria.

      
with open("mensaje.txt", "r", encoding="utf-8") as archivo:
    for linea in archivo:
        print(linea.strip())

    

    

      
Agregar sin borrar

      
with open("mensaje.txt", "a", encoding="utf-8") as archivo:
    archivo.write("\nSegunda línea")

      
Escribir varias líneas

      
lineas = ["Uno\n", "Dos\n", "Tres\n"]
with open("numeros.txt", "w", encoding="utf-8") as archivo:
    archivo.writelines(lineas)

      
writelines(), igual que write(), no agrega saltos de línea: cada elemento debe incluir su "\n".

Idea clave 7

  
Errores comunes y cómo prevenirlos

  

    
FileNotFoundErrorUsar "r" con un archivo inexistente, o una ruta incorrecta.

    
FileExistsErrorUsar "x" con un archivo que ya existe.

    
Contenido perdidoUsar "w" por accidente borra lo anterior sin aviso.

    
Datos incompletosOlvidar cerrar el archivo. Solución: with open().

    
UnicodeDecodeErrorNo especificar encoding al leer acentos y "ñ".

    
Solo cadenaswrite() no acepta números: archivo.write(str(25)).

    
Sin saltoswrite() no agrega "\n": escríbelo explícitamente.

    
PermissionErrorNo tener permisos sobre el archivo o la carpeta.

  

  

    
Manejo básico de errores

    
try:
    with open("datos.txt", "r", encoding="utf-8") as archivo:
        print(archivo.read())
except FileNotFoundError:
    print("El archivo no existe.")

Resumen

  
Lo esencial de open()

  

    
Abrir
open() devuelve un objeto archivo. Indica siempre encoding="utf-8".

    
Elegir el modo
"r" lee, "w" borra y escribe, "a" agrega, "x" solo crea.

    
Leer y escribir
read(), readline(), readlines(), write(), writelines(). Los saltos "\n" se escriben a mano.

    
Cerrar
with open() cierra el archivo al terminar el bloque, aun si ocurre una excepción.
