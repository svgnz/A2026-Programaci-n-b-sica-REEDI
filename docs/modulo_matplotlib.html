Idea clave 1

¿Qué es matplotlib?

Una biblioteca que representa datos mediante gráficas para facilitar su interpretación y comparación, y las guarda como imágenes (PNG, JPG, SVG o PDF) para reportes y presentaciones.

Instalarla en el entorno virtual

python -m pip install matplotlib
python -m pip freeze > requirements.txt
python -c "import matplotlib; print(matplotlib.__version__)"

matplotlib instala también dependencias como numpy y pillow, que aparecerán en requirements.txt.

Se usa para

  • Comparar cantidades entre categorías: barras verticales u horizontales.
  • Representar proporciones de un total: circular (pie).
  • Mostrar cambios en el tiempo: líneas.
  • Mostrar la relación entre dos variables numéricas: dispersión.

ISO 80000-1 y SI: ejes y unidades

  • Cada eje indica qué se mide y en qué: Tiempo / s (forma ISO) o Tiempo (s). Usa una sola forma en todo el documento.
  • Símbolos del SI sin punto ni plural, con espacio entre número y unidad: 5 kg, 25 °C, 50 %.
  • Sin unidad, dilo con claridad: "Número de estudiantes", "Calificación (0-100)".

Idea clave 3

¿Qué gráfica usar? y una escala honesta

Elige según la pregunta

Las barras deben iniciar en cero

Buenas prácticas

  • Ordena las barras de mayor a menor si el orden no importa.
  • Mismo color para la misma variable; colores distintos solo si informan.
  • Sin 3D, sombras ni decoraciones; no sobrecargues.
  • No dependas solo del par rojo/verde (daltonismo).
  • Indica la fuente y guarda con dpi=300 para documentos.

Idea clave 7

  
Barras horizontales, gráfica circular y errores comunes

  

    

      
plt.barh(): muchas categorías o nombres largos

      
lenguajes = ["Python", "JavaScript", "Java", "C++", "C#"]
votos = [18, 9, 6, 4, 3]
lenguajes.reverse()   # barh dibuja la primera categoría abajo
votos.reverse()
barras = plt.barh(lenguajes, votos, color="seagreen")
plt.bar_label(barras, padding=3)
plt.xlabel("Número de estudiantes")
plt.ylabel("Lenguaje")
plt.xlim(0, 20)

      

      
Datos ilustrativos. Las categorías van en el eje Y; xlabel describe los valores.

    

    

      
plt.pie(): partes de un total

      
rangos = ["Excelente (90-100)", "Bueno (80-89)",
          "Suficiente (70-79)", "No acreditado (<70)"]
estudiantes = [12, 15, 9, 4]
plt.pie(estudiantes, labels=rangos, autopct="%1.1f %%",
        startangle=90, counterclock=False)
plt.title("Distribución de calificaciones del grupo (n = 40)")
plt.axis("equal")

      

      
Datos ilustrativos. pie() calcula los porcentajes; startangle=90 y counterclock=False inician a las 12 y avanzan en sentido horario. Úsala solo si las partes forman un total y hay de 2 a 6 categorías.

    Actividad 3 · Revelar respuesta
    
La ventana muestra bien la gráfica, pero al abrir calificaciones.png está en blanco. ¿Por qué y cómo se corrige?

    
plt.bar(estudiantes, calificaciones)
plt.title("Calificaciones finales por estudiante")
plt.show()
plt.savefig("calificaciones.png", dpi=300)

    

    

      
Por qué: plt.show() detiene el programa hasta cerrar la ventana; al cerrarla, la figura se borra. Cuando se ejecuta savefig(), ya no hay nada que guardar.

      
Corrección: llamar a savefig() antes de show().

      
plt.savefig("calificaciones.png", dpi=300)
plt.show()
