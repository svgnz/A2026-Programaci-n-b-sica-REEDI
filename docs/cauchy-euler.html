Cauchy-Euler paso a paso

Del cambio de variable $ax + b = e^w$ a la solución general.

Objetivo de aprendizaje

Resolver ecuaciones diferenciales homogéneas de Cauchy-Euler de orden 2 mediante el cambio de variable $ax + b = e^w$ y el operador $D = \f{d}{dw}$, hasta expresar la solución general en la variable $x$, a partir de la fórmula general de las derivadas.

Idea clave 1

¿Qué es una ecuación de Cauchy-Euler?

Una ecuación diferencial lineal de la forma

$a_n(ax + b)^n\f{d^ny}{dx^n} + a_{n−1}(ax + b)^{n−1}\f{d^{n−1}y}{dx^{n−1}} + … + a_1(ax + b)\f{dy}{dx} + a_0y = g(x)$

con $a_i ∈ ℝ$, $i = 1, 2, 3, …, n$, es llamada ecuación diferencial de Cauchy-Euler (EDCE).

Observación

El caso más frecuente es cuando $a = 1$ y $b = 0$:

$a_nx^n\f{d^ny}{dx^n} + a_{n−1}x^{n−1}\f{d^{n−1}y}{dx^{n−1}} + … + a_1x\f{dy}{dx} + a_0y = g(x)$
Ejemplo

$x^2y″ − 2y = 0$ es una EDCE homogénea de orden 2: $a = 1$, $b = 0$, $a_2 = 1$, $a_1 = 0$, $a_0 = −2$ y $g(x) = 0$.

Idea clave 2

El cambio de variable $ax + b = e^w$

Para resolver una EDCE se hace el cambio de variable $ax + b = e^w$. Al diferenciar respecto a $x$:

$a = e^w\f{dw}{dx}$   ⇒   $ae^{−w} = \f{dw}{dx}$

Con la regla de la cadena y el operador $D = \f{d}{dw}$, la primera derivada queda:

$\f{dy}{dx} = \f{dy}{dw}·\f{dw}{dx} = \f{dy}{dw}·ae^{−w}$   ⇒   $\f{dy}{dx} = ae^{−w}Dy$
Ejemplo

En el caso $a = 1$, $b = 0$: $x = e^w$, por lo que $w = \ln(x)$ y $\f{dy}{dx} = e^{−w}Dy$.

Actividad 2 · Revelar respuesta

Si el cambio de variable es $2x + 3 = e^w$, ¿cuánto vale $\f{dw}{dx}$ y cómo queda $\f{dy}{dx}$ en términos de $D$?

Aquí $a = 2$ y $b = 3$. Al diferenciar: $2 = e^w\f{dw}{dx}$, así que $\f{dw}{dx} = 2e^{−w}$.

Por la regla de la cadena: $\f{dy}{dx} = 2e^{−w}Dy$.

Error habitual: escribir $e^{−w}Dy$ y olvidar el factor $a = 2$, que solo desaparece cuando $a = 1$.

Idea clave 3

Derivadas de orden superior con el operador $D$

Aplicando de nuevo la regla de la cadena se obtiene la segunda derivada:

$\f{d^2y}{dx^2} = a^2e^{−2w}\left[\f{d^2y}{dw^2} − \f{dy}{dw}\right] = a^2e^{−2w}[D^2 − D]y$  ⇒  $\f{d^2y}{dx^2} = a^2e^{−2w}(D − 1)Dy$
DerivadaForma con el operador D
$\f{dy}{dx}$$ae^{−w}Dy$
$\f{d^2y}{dx^2}$$a^2e^{−2w}(D − 1)Dy$
$\f{d^3y}{dx^3}$$a^3e^{−3w}(D − 2)(D − 1)Dy$
$\f{d^4y}{dx^4}$$a^4e^{−4w}(D − 3)(D − 2)(D − 1)Dy$
$\f{d^ny}{dx^n}$$a^ne^{−nw}[D − (n − 1)]⋯(D − 2)(D − 1)Dy$
Ejemplo

Con $a = 1$, $b = 0$ ($x = e^w$): $y″ = e^{−2w}(D − 1)Dy$. Al multiplicar por $x^2 = e^{2w}$ se obtiene $x^2y″ = (D − 1)Dy$.

    Idea clave 5

    Regresar a la variable original $x$

    La solución $y(w) = C_1e^{2w} + C_2e^{−w}$ debe escribirse en términos de $x$. Hay dos formas equivalentes:

    Forma 1 · Reescribir y(w)
    $y(w) = C_1(e^w)^2 + C_2(e^w)^{−1}$

    Como $x = e^w$:

    $y(x) = C_1x^2 + C_2x^{−1}$
    Forma 2 · Despejar w

    Como $x = e^w$ ⇒ $w = \ln(x)$:

    $y(x) = C_1e^{2\ln(x)} + C_2e^{−\ln(x)}$
    $y(x) = C_1e^{\ln(x^2)} + C_2e^{\ln(x^{−1})}$
    $y(x) = C_1x^2 + C_2x^{−1}$
    Actividad 5 · Revelar respuesta

    Una EDCE con $x = e^w$ tiene solución $y(w) = C_1e^{3w} + C_2e^{−2w}$. Escribe $y(x)$ con la Forma 1 y con la Forma 2.

    Forma 1: $y = C_1(e^w)^3 + C_2(e^w)^{−2} = C_1x^3 + C_2x^{−2}$.

    Forma 2: $y = C_1e^{3\ln(x)} + C_2e^{−2\ln(x)} = C_1e^{\ln(x^3)} + C_2e^{\ln(x^{−2})} = C_1x^3 + C_2x^{−2}$.

    Error habitual: dejar la respuesta en $w$ o escribir $e^{3x}$, como si la ecuación original tuviera coeficientes constantes.

        Idea clave 7

        La nueva ecuación tiene coeficientes constantes

        Al sustituir $ax + b = e^w$ y cada una de las derivadas, la EDCE se convierte en una ecuación diferencial lineal con coeficientes constantes en la variable $w$.

        Ejemplo

        $x^2y″ − 2y = 0$ (coeficientes variables) se transforma en $(D^2 − D − 2)y = 0$ (coeficientes constantes), que se resuelve con su ecuación auxiliar.

        Si $g(x) ≠ 0$, la nueva ecuación es no homogénea y se resuelve con los métodos vistos: coeficientes indeterminados o variación de parámetros.

        Cierre

        Resumen

        • Una EDCE tiene coeficientes $a_i(ax + b)^i$ en la derivada de orden $i$; el caso más frecuente es $a = 1$, $b = 0$.
        • Se resuelve con el cambio de variable $ax + b = e^w$, de donde $\f{dw}{dx} = ae^{−w}$.
        • Con $D = \f{d}{dw}$: $\f{d^ny}{dx^n} = a^ne^{−nw}[D − (n − 1)]⋯(D − 2)(D − 1)Dy$.
        • La ecuación resultante es lineal con coeficientes constantes; si es homogénea se resuelve con su ecuación auxiliar.
        • Con raíces reales distintas: $y(w) = C_1e^{m_1w} + C_2e^{m_2w}$, y se regresa a $x$ con $x = e^w$ o $w = \ln(x)$.
