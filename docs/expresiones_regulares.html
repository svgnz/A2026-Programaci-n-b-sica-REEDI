Idea clave 1

¿Qué son las expresiones regulares?

Son patrones que permiten buscar, identificar, validar y transformar texto según reglas definidas. En Python se usan con el módulo integrado re: no se instala, pero sí se importa.

Antes de usarlo

import re

¿Para qué sirven?

  • Identificar números dentro de un texto.
  • Verificar si una cadena tiene un formato: matrícula, correo, teléfono, fecha.
  • Buscar palabras o patrones específicos.
  • Reemplazar, extraer o dividir fragmentos de texto.

Ejemplo

import re

texto = "El grupo tiene 35 estudiantes y 4 equipos"
numeros = re.findall(r"\d+", texto)
print(numeros)   # ['35', '4']

El patrón \d+ significa "uno o más dígitos consecutivos". La r antes de las comillas indica una cadena cruda; la verás a detalle en la diapositiva 8.

Idea clave 2

Los símbolos de un patrón

Clases de caracteres

\d
Un dígito (0 a 9).
\w
Letra, dígito o "_". En Python 3 incluye acentos y "ñ".
\s
Espacio, tabulador o salto de línea.
\D \W \S
Lo contrario de \d, \w y \s.
.
Cualquier carácter excepto el salto de línea.
[abc] [a-z]
Un carácter del conjunto o del rango.
[^0-9]
Un carácter que NO esté en el conjunto.

Cuantificadores y anclas

+ * ?
Una o más · cero o más · cero o una vez.
{n} {n,m} {n,}
Exactamente n · entre n y m · n o más.
^ $
Inicio y final del texto.
\b
Límite de palabra: \bsol\b no toma "soldado".
| ( )
Alternativa · agrupar y capturar.
\
Escapa un especial: \. busca un punto.

Se escapan para buscarlos tal cual: . ^ $ * + ? { } [ ] \ | ( )

Probador de patrones

Coincidencias resaltadas

El probador usa el motor de expresiones del navegador; con los símbolos de esta guía da el mismo resultado que Python, salvo \w, que aquí no incluye acentos ni "ñ".

Idea clave 6

  
Buscar, revisar el inicio o validar todo

  

    

      

        
LlamadaResultado¿Por qué?

        
          
re.search(r"\d+", "abc123")Match "123"Busca en cualquier parte del texto.

          
re.match(r"\d+", "abc123")NoneSolo revisa el inicio, y el texto no inicia con dígitos.

          
re.fullmatch(r"\d+", "123")Match "123"Todo el texto son dígitos.

          
re.fullmatch(r"\d+", "123abc")NoneSobra "abc".

        
      

    

  

  

    

      
Verificar antes de usar .group()

      
texto = "Inscripción: 15/08/2026"
resultado = re.search(r"\d{2}/\d{2}/\d{4}", texto)
if resultado:
    print("Fecha encontrada:", resultado.group())
else:
    print("No se encontró fecha")

      
Si el resultado es None, llamar a .group() produce AttributeError.

    

    

      
Capturar partes con grupos ( )

      
correo = "ana.lopez@uanl.edu.mx"
r = re.fullmatch(r"([\w.]+)@([\w.]+)", correo)
if r:
    print("Usuario:", r.group(1))   # ana.lopez
    print("Dominio:", r.group(2))   # uanl.edu.mx

      
Si el patrón tiene grupos, findall() devuelve solo lo capturado en los grupos.

Idea clave 7

  
La r del patrón y los errores comunes

  

    

      
La barra invertida significa algo en dos niveles

      

        
Python
En una cadena normal inicia un escape: "\n" salto, "\t" tabulador, "\b" retroceso.

        
Módulo re
Inicia un símbolo: \d dígito, \s espacio, \b límite de palabra.

      

      
Con r (cadena cruda), el patrón llega al módulo re exactamente como se escribió. La r no forma parte del texto: r"\d+" sigue siendo str.

      
len("\n")    # 1
len(r"\n")   # 2

    

    

      
Cuándo cambia el resultado

      
texto = "sol soldado"
re.findall(r"\bsol\b", texto)   # ['sol']

      
Sin r, "\d+" todavía funciona, pero desde Python 3.12 muestra SyntaxWarning: invalid escape sequence '\d'. Depender de eso es mala práctica: con otros patrones falla. Alternativa sin r: duplicar barras, "\\d+", aunque se lee peor.

    

  

  

    
Sin r"\b" se vuelve retroceso y el patrón falla.

    
match() ≠ buscarmatch() solo revisa el inicio del texto.

    
Validar con search()"abc123xyz" pasaría como número. Usa fullmatch().

    
AttributeErrorUsar .group() sobre None.

    
Sin escaparEl patrón 3.5 también toma "3x5"; lo correcto es 3\.5.

    
+ contra *\d* también coincide con cadenas vacías.

    
Cadenas, no enterosfindall() devuelve str; convierte con int().

    
re.errorParéntesis o corchetes sin cerrar.

    
Codicioso.* toma lo más posible; .*? toma lo menos posible.

Resumen

  
Lo esencial de las expresiones regulares

  

    
El patrón
Clases (\d \w \s), cuantificadores (+ * ? {n}) y anclas (^ $ \b). Escapa los especiales.

    
La función
findall() extrae todo, search() la primera, fullmatch() valida, sub() reemplaza y split() divide.

    
El resultado
Verifica que no sea None antes de usar .group(). Convierte con int() antes de calcular.

    
La r
Escribe siempre los patrones como cadenas crudas: r"...".
