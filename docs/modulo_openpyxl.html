Idea clave 1

¿Qué es openpyxl?

Una biblioteca que lee, crea y modifica archivos de Excel en formato .xlsx sin necesidad de tener Microsoft Excel instalado: leer y escribir celdas, crear libros y hojas, agregar filas, aplicar formato básico y escribir fórmulas.

Instalarla en el entorno virtual

No es parte de la biblioteca estándar. Con el entorno del proyecto activado:

python -m pip install openpyxl
python -m pip freeze > requirements.txt
python -c "import openpyxl; print(openpyxl.__version__)"

La segunda línea actualiza las dependencias; la tercera verifica la instalación.

Conceptos básicos

Libro
Archivo de Excel completo (.xlsx). workbook
Hoja
Pestaña dentro del libro; puede haber varias. worksheet
Celda
Columna + fila. Contiene texto, número, fecha, fórmula o nada (None).
Fila
Horizontal; se identifica con número: 1, 2, 3…
Columna
Vertical; con letra (A, B, C…) o número (1, 2, 3…).
libro→libro["Hoja"]→hoja["A1"]

Importante: filas y columnas inician en 1, no en 0 como las listas de Python.

Libros, hojas y celdas

Libros y hojas

Workbook()
Crea un libro nuevo en memoria, con una hoja "Sheet".

Nombre de la hoja (leer o cambiar).

Última fila y última columna con datos.

Idea clave 3

  
Crear un archivo Excel

  
Problema: crear calificaciones.xlsx con los nombres de tres estudiantes y sus calificaciones.

  

    

      
from openpyxl import Workbook

libro = Workbook()
hoja = libro.active
hoja.title = "Calificaciones"

hoja.append(["Estudiante", "Calificación"])
hoja.append(["Ana", 95])
hoja.append(["Luis", 88])
hoja.append(["Marta", 92])

libro.save("calificaciones.xlsx")
print("Archivo creado correctamente")

      
    
        
  1. Workbook() crea el libro en memoria; el archivo aún no existe.
    2. 
        
  2. libro.active obtiene la hoja activa, llamada "Sheet"; hoja.title la renombra.
    3. 
        
  3. append() agrega cada lista como fila: cada elemento ocupa una columna.
    4. 
        
  4. save() crea el archivo en la carpeta de trabajo. Hasta aquí no se guarda nada en disco.
    5. 
      

    

    

      
Resultado en Excel

      

      
    
        
  • append() siempre agrega al final; no modifica una celda específica.
    • 
        
  • Los números van sin comillas (95, no "95") para poder sumarlos o promediarlos.
    • 
        
  • Si ya existe un archivo con el mismo nombre, save() lo reemplaza sin avisar.

Idea clave 6

  
Leer un archivo Excel

  

    

      
from openpyxl import load_workbook

libro = load_workbook("calificaciones.xlsx")
hoja = libro.active

for fila in hoja.iter_rows(min_row=2, values_only=True):
    print(fila)

      

        
min_row, max_row
Primera y última fila a recorrer.

        
min_col, max_col
Primera y última columna (números).

        
values_only=True
Devuelve los valores en una tupla, en lugar de objetos celda.

      

      
Desempaquetar y leer celdas

      
for nombre, calificacion in hoja.iter_rows(min_row=2, max_col=2,
                                          values_only=True):
    print(nombre, "obtuvo", calificacion)

print(hoja["A2"].value)                   # Ana
print(hoja.cell(row=3, column=2).value)   # 88

      
max_col=2 asegura dos valores por fila; con más columnas el desempaquetado fallaría con ValueError.

    Actividad 3 · Revelar respuesta
    
Se quiere mostrar el encabezado de la columna A del libro calificaciones.xlsx (hoja "Calificaciones"). ¿Qué muestra este código, por qué y cómo se corrige?

    
print(hoja["A1"])

    

    

      
Muestra: <Cell 'Calificaciones'.A1>.

      
Por qué: hoja["A1"] es la celda (el objeto), no su contenido.

      
Corrección: leer su valor con .value.

      
print(hoja["A1"].value)   # Estudiante

    

  







  
Idea clave 7

  
Modificar, calcular y evitar errores

  

    

      
Modificar una celda y guardar

      
libro = load_workbook("calificaciones.xlsx")
hoja = libro["Calificaciones"]
hoja["B3"] = 90                  # Luis: de 88 a 90
libro.save("calificaciones.xlsx")

      
Escribir una fórmula

      
hoja["D1"] = "Promedio"
hoja["D2"] = "=AVERAGE(B2:B4)"

      
Texto que inicia con = y funciones en inglés (AVERAGE, SUM, MAX), aunque Excel esté en español. Excel la calcula al abrir el archivo; openpyxl no.

    

    

      
Calcular el promedio con Python

      
suma = 0
cantidad = 0
for nombre, calificacion in hoja.iter_rows(min_row=2, max_col=2,
                                          values_only=True):
    suma = suma + calificacion
    cantidad = cantidad + 1
print("Promedio:", suma / cantidad)

      
Manejo básico de errores

      
try:
    libro = load_workbook("calificaciones.xlsx")
    hoja = libro.active
    hoja.append(["Pedro", 85])
    libro.save("calificaciones.xlsx")
except FileNotFoundError:
    print("El archivo no existe.")
except PermissionError:
    print("Cierre el archivo en Excel e intente de nuevo.")

    

  

  

    
FileNotFoundErrorload_workbook() con un archivo inexistente o ruta incorrecta.

    
PermissionErrorEn Windows, save() con el archivo abierto en Excel.

    
Sin save()Los cambios se pierden al terminar el programa.

    
InvalidFileExceptionArchivos .xls antiguos; guárdalos como .xlsx. Para .csv usa open() o csv.

    
FórmulasSe leen como texto; con data_only=True, el último resultado guardado por Excel o None.

    
ValueErrorhoja.cell(row=0, column=0): filas y columnas inician en 1.

    
KeyErrorlibro["Calificacion"] si la hoja no existe; revisa sheetnames.

    
Texto, no númeroappend(["Ana", "95"]) guarda texto; usa 95 o int("95").

    
NoneCeldas vacías: valida antes de operar para evitar TypeError.

    
Datos sensiblesRevisa que no haya matrículas, calificaciones o correos antes de compartir.

Resumen

  
Lo esencial de openpyxl

  

    
Abrir
Workbook() crea un libro nuevo; load_workbook() abre uno existente.

    
Ubicar
hoja["B3"] o hoja.cell(row=3, column=2); filas y columnas desde 1; el contenido, con .value.

    
Escribir y leer
append() agrega filas al final; iter_rows(values_only=True) las recorre.

    
Guardar
save() lleva los cambios al disco y reemplaza sin avisar.
