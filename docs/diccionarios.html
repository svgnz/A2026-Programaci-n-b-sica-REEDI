Diccionarios en Python: consulta y recorre datos con clave y valor

Objetivo de aprendizaje

Aplicar los métodos get(), keys(), values() e items() de los diccionarios de Python para consultar y recorrer datos clave–valor, a partir de un problema resuelto con análisis EPS y un algoritmo estilo Osvaldo Cairó.

Avanza con las flechas del teclado o con los botones de abajo.

Idea 1 · Qué es

Un diccionario guarda pares clave : valor

Cada clave identifica un dato, y con ella se consulta su valor. Funciona como una ficha: buscas por la etiqueta, no por la posición.

alumno = {
    "nombre": "Ana",
    "edad": 18,
    "carrera": "Matemáticas"
}

Las claves no se repiten. Si asignas un valor a una clave existente, se reemplaza el anterior.

Ficha alumno

"nombre"→"Ana"
"edad"→18
"carrera"→"Matemáticas"

En esta presentación las claves siempre aparecen en ámbar y los valores en azul.

Idea 2 · Consultar

Corchetes o get(): la diferencia aparece cuando la clave no existe

print(alumno["nombre"])       # Ana
print(alumno.get("nombre"))   # Ana

print(alumno["semestre"])
KeyError: 'semestre'

El KeyError es un error de ejecución: el código es válido, pero falla al buscar una clave que no está. get() lo evita.

Idea 3 · Valor alternativo

get(clave, alternativo) responde aunque falte el dato

print(alumno.get("semestre", "No registrado"))
No registrado

El segundo argumento es lo que se devuelve si la clave no existe. Si la clave sí existe, se ignora y se devuelve su valor real.

Uso típico: datos opcionales, como un correo o un teléfono que no todos los alumnos registran.

Actividad 2 · Predice y revela

Escribe en tu libreta qué imprime cada línea y después revisa.

alumno = {"nombre": "Ana", "edad": 18, "carrera": "Matemáticas"}

print(alumno.get("carrera", "No registrado"))
print(alumno.get("correo", "Sin correo"))
Matemáticas
Sin correo

La clave "carrera" existe, así que se ignora el alternativo. "correo" no existe, así que se devuelve "Sin correo".

Idea 4 · Claves y valores

keys() da las etiquetas; values() da el contenido

keys()

for clave in alumno.keys():
    print(clave)
nombre
edad
carrera

for clave in alumno: también recorre las claves. Con keys() el código es más explícito.

values()

for valor in alumno.values():
    print(valor)
Ana
18
Matemáticas

Nota técnica: en Python 3 estos métodos devuelven vistas (dict_keys, dict_values), no listas. Para una lista usa list(alumno.keys()).

Idea 5 · Todo junto

items() recorre clave y valor al mismo tiempo

for clave, valor in alumno.items():
    print(clave, ":", valor)
nombre : Ana
edad : 18
carrera : Matemáticas

Cada elemento es una tupla ('nombre', 'Ana'); el for la desempaca en dos variables.

Para reflexionar: los pasos 12 a 21 son una búsqueda completa con bandera. En Python, una sola línea con get() hace ese trabajo.

Diccionario de variables
  • PARES: arreglo unidimensional de PAR, de 1 a 3. Datos del alumno como pares clave–valor.
  • NOM, EDAD, CAR: cadenas. Nombre, edad y carrera del alumno.
  • BUS: cadena. Clave que se desea consultar.
  • RES: cadena. Valor encontrado o valor alternativo.
  • BAN: booleano. Indica si la clave fue encontrada.
  • I: entero. Controla los recorridos del arreglo.

Actividad 4 · Revela la solución

      
      


libro = {
    "titulo": "Rayuela",
    "autor": "Julio Cortázar",
    "anio": 1963
}
print("editorial", ":", libro.get("editorial", "Sin editorial"))

for valor in libro.values():
    print(valor)

for clave, valor in libro.items():
    print(clave, ":", valor)

autor : Julio Cortázar
anio : 1963

        
Observa que el diccionario de Python admite valores de distintos tipos: 1963 es entero y el resto son cadenas.
